# 🌪️ Vortex Velocity 3D

A high-performance, browser-based 3D super car racing and customization game built with modern WebGL technologies, featuring realistic vehicle handling physics, dynamic lighting, custom shaders, and procedural audio synthesis.

## ✨ Key Features
- **Custom 3D Garage & Showroom:** Real-time car inspection, custom paint jobs, and styling.
- **Arcade Physics:** Responsive drifting, acceleration curves, and nitro boosts.
- **Immersive Audio Engine:** Procedural engine roars and sound effects driven by the Web Audio API.

## 🚀 Quick Start
Open `index.html` in any modern browser or run via a local static server.
